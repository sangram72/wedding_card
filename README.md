# Sangram & Tiasha — Animated Wedding Invitation

A Next.js wedding invitation designed as an interactive page-flipping book.

## Requirements
- Node.js 20.9 or later (LTS recommended)
- npm

## Install and run
1. Extract this ZIP.
2. Open the extracted `sangram-tiasha-wedding` folder in VS Code.
3. Open Terminal in that folder and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Features
- Interactive page-flip book (touch/swipe and mouse)
- Animated guide explaining how to turn pages
- Eight invitation pages
- Wedding: 9 March 2027, NKDA Community Hall, Biswa Bangla, New Town, 2nd & 3rd floors
- Reception: 11 March 2027, Tulsi Palace, 56 Durganagar, near Dhalai Karkhana Bus Stand, Delhi Road
- Google Maps search links for both venues
